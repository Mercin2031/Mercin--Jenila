Chapter one

Origin story

Hi, I'm Mercin. I'm in the first year of my B.Tech in Information Technology, which means most of my story is still unwritten, and I like it that way. Every week brings a new tool, a new error message, or a thing I didn't know I'd enjoy.

The project that made me feel like a builder was a hackathon idea: using AI to catch eye diseases like glaucoma and retinopathy early. I'm not an expert yet. But it showed me that code can be about people, not only screens.

Right now I'm learning the basics properly, the unglamorous foundations, so the next idea I build doesn't fall apart. If you're working on something and need a curious teammate, say hi.
